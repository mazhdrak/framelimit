How to Use This Database

Start with the exact model code, not only the marketing family. Manufacturers can sell one laptop name with different GPUs, power limits, panels, memory, and regional suffixes. Open the source and retailer links, then confirm the delivered configuration before buying.

Use TGP to identify meaningful power-class differences inside the same GPU tier. For performance, compare only matching game, resolution, preset, upscaling, Frame Generation, firmware, and power-mode evidence. A higher maximum value can still lose in a particular workload.

What is laptop GPU TGP?

TGP is a graphics-power specification. The laptop value here is the maximum graphics power published for the exact OEM configuration, including Dynamic Boost where the manufacturer includes it.

Does higher TGP always mean higher FPS?

No. Cooling, firmware, CPU load, memory, game settings, and the GPU's voltage-frequency behavior also affect performance. TGP narrows the comparison; it does not replace benchmarks.

How should I compare the same GPU at different TGP?

Match the exact model code, game, resolution, preset, ray tracing, upscaling, Frame Generation and performance mode. Do not convert the wattage spread into an assumed FPS uplift.

Why are some values marked “Not published”?

The exact configuration has a traceable specification source, but that source does not expose a reliable maximum graphics-power figure. FRAMELIMIT leaves the field empty instead of copying a value from a different regional configuration.

How often is the database checked?

Each row carries its own source-check date from the central FRAMELIMIT catalog. The current database snapshot was checked through July 15, 2026.
