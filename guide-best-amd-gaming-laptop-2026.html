AMD Gaming Technologies Explained

TechnologyWhat it doesRelevant supportBenchmark rule
FSR UpscalingReconstructs a higher-resolution image from a lower internal resolution.FSR version, hardware compatibility, and game integration must be checked per title and feature.Always state version and Quality/Balanced/Performance mode.
FSR 3 Frame GenerationInserts one generated frame between rendered frames.Supported hardware is broad, but the game must include compatible FSR integration.Show generated FPS separately from rendered FPS.

Check Each FSR Feature Separately Do not treat an FSR generation name as universal support for every Radeon laptop. Check AMD's current compatibility information and the individual game's implementation, then record upscaling, frame generation, and latency features separately.

Benchmark Policy for Radeon Laptops

FRAMELIMIT will publish a Radeon FPS table only when the exact laptop configuration, GPU power mode, resolution, preset, driver, FSR version, quality mode, and frame-generation state are known. Native, upscaled, and generated frame rates will be separate results. We will not use a vendor GPU claim as a laptop benchmark.
